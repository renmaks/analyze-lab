# analyze-lab
**Лабораторная работа по сбору и анализу датасета, связанного с рынком конкретной отрасли, с приведением выводов.**

Описание алгоритма из блокнота:
1. Собираем из csv-файла необходимый нам датасет (юридические лица одной отрасли)
2. Парсим из налоговой для выбранных компаний нужные для подсчёта метрик данные.
3. Считаем метрики.
4. Строим графики.
5. Строим карту (топ-500 компаний по прибыльности)

**Сделанные на основе полученного выводы:**<br>
**1. Вывод по графикам:**<br>
Графики показывают распределение процентного изменения чистой прибыли между сравниваемыми годами. Для корректного сравнения периодов используется единая панель компаний, имеющих данные за все рассматриваемые годы и положительную чистую прибыль во всех базовых годах.<br>
Отрицательное процентное изменение означает снижение чистой прибыли относительно базового года, но само по себе не означает, что компания стала убыточной. Поэтому отдельно рассчитывается доля компаний, у которых в конечном году чистая прибыль стала нулевой или отрицательной.<br>
Также на всех графиках виден более уверенный положительный хвост - это те компании, что получают прибыль. Причём некоторые аномально многократную, что может указывать на их скромную базовую прибыль.<br>
Большая часть компаний движется умеренно, показывая адекватный уровень прибыльности. Всплеск у нуля со временем уменьшается. Сфера имеет долгий период окупаемости.<br>

В распределениях присутствуют как отрицательные, так и положительные изменения чистой прибыли. Существенные положительные процентные изменения у отдельных компаний могут быть связаны в том числе с низкой прибылью в базовом году. Построенные показатели характеризуют лишь динамику чистой прибыли.<br>

**2. Вывод по карте:**<br>
Карта отображает топ-500 компаний по суммарной выручке за 2021–2025 годы среди организаций, для которых доступна полная отчётность за все пять лет. В текущей выборке полная пятилетняя отчётность имеется у 6398 из 8841 компаний, поэтому рейтинг не является топ-500 среди всех организаций исходной выборки.<br>
Из 500 компаний рейтинга координаты удалось получить для 418. Используемые координаты соответствуют уровню населённого пункта, а не точному адресу организации, поэтому карта отражает прежде всего географическое распределение компаний по городам и другим населённым пунктам.<br>

Большое абсолютное количество компаний в Москве, Санкт-Петербурге и других крупных регионах не означает автоматически более высокую прибыльность или эффективность компаний этих регионов. Для регионального сравнения следует учитывать размер исходной региональной выборки и анализировать, например, долю компаний региона, вошедших в топ-500, медианную выручку, прибыль или показатели рентабельности.<br>
Сибирь и Дальний Восток представлены меньшим количеством компаний, но там присутствуют отдельные организации с высокой суммарной выручкой.<br>
